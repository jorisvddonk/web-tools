web-tools

Simple web tools that perform simple functions.

data & text

  • json formatter / validator
    Format, minify, sort and validate JSON, with exact error locations.
  • json schema tester
    Validate a JSON instance against draft-04, draft-06, draft-07, 2019-09 or 2020-12.
  • json to types
    Infer TypeScript interfaces, Zod schemas or Go structs from a JSON sample.
  • yaml ↔ json
    Convert between YAML and JSON, including multi-document YAML.
  • jsonpath tester
    Query JSON with JSONPath and see matched values and paths.
  • csv ↔ json
    Convert CSV or TSV to JSON and back, with a table preview.
  • text diff
    Compare two blocks of text side by side or unified, and copy a standard patch.
  • regex tester
    Test JavaScript regular expressions live, inspect capture groups and preview replacements.
  • case converter
    Convert between camelCase, snake_case, kebab-case, CONSTANT_CASE, slug and more.
  • line tools
    Sort, dedupe, trim, reverse, shuffle and number lines of text.
  • escape / unescape
    Escape and unescape HTML entities, JSON, Python, shell and URL components.
  • unicode inspector
    Inspect code points, UTF-8/UTF-16 bytes, graphemes, invisible characters and normalization.
  • markdown table formatter
    Clean up Markdown tables, or convert CSV/TSV into aligned Markdown.
  • .env ↔ json / yaml
    Convert dotenv files to JSON or YAML and back, with quoting and type coercion.
  • base64
    Encode text to base64 and decode it back, entirely in your browser.

web, time & security

  • jwt decoder
    Inspect JWT headers, payloads and claims, and verify HS256/384/512 signatures.
  • url & query string inspector
    Break a URL into its components, edit query parameters, and rebuild it.
  • curl converter
    Turn curl commands into fetch, axios, Python requests or Go code.
  • unix timestamp converter
    Convert epoch seconds, milliseconds, microseconds and nanoseconds to human dates and back.
  • cron expression explainer
    Describe cron expressions and preview their next run times.
  • hash calculator
    Compute SHA-1, SHA-256, SHA-384 and SHA-512 digests of text or files.
  • uuid / ulid generator
    Generate UUID v4, UUID v7, ULID and NanoID values locally.

images & design

  • diagram renderer
    Render nine diagram formats with highlighting, examples, dark mode and a guided recommender.
  • image resizer / converter
    Resize, compress and convert images to JPEG, PNG, WebP or AVIF.
  • favicon generator
    Generate favicon PNGs and a multi-size favicon.ico from any image.
  • qr code generator / decoder
    Generate QR codes and read them from images.
  • color converter & contrast checker
    Convert HEX, RGB, HSL, HSV and OKLCH, and check WCAG contrast.
  • css generators
    Generate clamp() sizes, gradients and box shadows with live previews.
  • svg viewer / optimizer
    Preview SVG and strip comments, metadata, scripts and extra whitespace.
  • palette
    Extract an image palette, copy hex/RGBA lists or download a palette PNG.
  • rgba_extractor
    Extract pixels as a flat RGBA array, tuples or JSON with dimensions.
