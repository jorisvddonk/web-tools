# web-tools

web-tools is a collection of small, single-purpose utilities that run entirely in your browser. There is no account, no upload and no server-side processing: text, schemas, images and files stay on your machine.

**The tools live at <https://jorisvddonk.github.io/web-tools/>.**

This book is the manual. It is organised with the [Diátaxis](https://diataxis.fr/) framework, so each page does one job:

| If you want to… | Read |
| --- | --- |
| learn by doing, from zero | [Tutorials](tutorials/first-five-minutes.md) |
| accomplish a specific task | [How-to guides](how-to/format-and-validate-json.md) |
| look up formats, keys or limits | [Reference](reference/tools.md) |
| understand how it works and why | [Explanation](explanation/architecture.md) |

## The tools at a glance

| Area | Tools |
| --- | --- |
| Data and text | JSON formatter, JSON Schema tester, JSON to types, YAML ↔ JSON, JSONPath, CSV ↔ JSON, diff, regex, case, lines, escape, unicode, Markdown tables, `.env`, base64 |
| Web, time and security | JWT decoder, URL inspector, curl converter, timestamps, cron, hashes, UUID/ULID |
| Images and design | Diagram renderer, image resizer, favicon generator, QR codes, colour and contrast, CSS generators, SVG viewer, palette, RGBA extractor |

See [Tools](reference/tools.md) for the full table with links.
